# 🧠 Lógica de Programação

Repositório com os exercícios e projetos que desenvolvidos no curso de **Algoritmo e logica de programação**, oferecido pela empresa **Hashtag Treinamentos** (carga horária: **2 horas**, concluído em **01/2024**).

O **objetivo foi praticar os fundamentos de lógica de programação**, necessários para desenvolver habilidades de análise de dados.

---

## 📚 O que aprendi

- Variáveis e tipos de dados
- Operadores aritméticos, lógicos e de comparação
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`for`, `while`)
- Listas, dicionários e outras estruturas de dados
- Funções e modularização do código
- Leitura e escrita de arquivos
- Depuração e boas práticas de escrita de código

## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/[SEU-USUARIO]/logica-de-programacao.git
   cd logica-de-programacao
   ```
2. Tenha o **[Python 3.x / outra linguagem]** instalado.
3. Execute qualquer exercício:
   ```bash
   python 03-condicionais/exercicio_01.py
   ```
